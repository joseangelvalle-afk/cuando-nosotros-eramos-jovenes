# Cuando nosotros éramos jóvenes — Android

Proyecto Android de la versión V5 corregida del juego. Funciona sin Internet: la interfaz, el tablero y las preguntas están incluidos dentro de la aplicación.

## Generar el APK con GitHub
1. Crea un repositorio nuevo en GitHub.
2. Sube **el contenido de esta carpeta** (no una carpeta contenedora adicional).
3. Abre la pestaña **Actions** del repositorio.
4. Entra en **Compilar APK Android**. Si no se ha iniciado automáticamente, pulsa **Run workflow**.
5. Cuando termine con un check verde, abre la ejecución.
6. En **Artifacts**, descarga **Cuando-nosotros-eramos-jovenes-APK**.
7. Descomprime ese ZIP: dentro estará `Cuando_nosotros_eramos_jovenes.apk`.

La aplicación está configurada para Android 6.0 o posterior y orientación horizontal.
